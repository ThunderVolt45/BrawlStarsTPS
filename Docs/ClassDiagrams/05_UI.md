# 클래스 다이어그램 — 5. UI (UMG Widgets)

UMG 위젯 계층입니다. 거의 모든 위젯이 `UBrawlUserWidget`(WidgetController 패턴 + 공통 클릭 SFX)을 상속하며, 인게임 HUD / 스킬 게이지 / 로비·메뉴 흐름으로 나뉩니다.

> 위치: `Source/BrawlStarsTPS/Public/UI/`

---

## 5.1 위젯 베이스 & 인게임 HUD

```mermaid
classDiagram
```

## 5.2 스킬 게이지 위젯 (Super / Hyper / Gadget)

`UBrawlSkillWidget`이 충전률(`SetPercent`)·준비 상태(`SetIsReady`)·아이콘의 공통 인터페이스를 제공하고, 각 스킬이 고유 연출(플래시, 쿨다운 텍스트, 활성 게이지)을 추가합니다.

```mermaid
classDiagram
    class UBrawlUserWidget
    class UBrawlSkillWidget {
        +SetPercent(pct) void
        +SetIsReady(bReady) void
        +SetSkillIcon(icon) void
        #ImageProgress : UImage
        #ImageIcon : UImage
        #ProgressMaterialDynamic : UMaterialInstanceDynamic
    }
    class UBrawlSuperWidget {
        +SetPercent(pct) void
        -AnimFlash : UWidgetAnimation
    }
    class UBrawlHyperWidget {
        +SetIsActive(bActive) void
        +SetActivePercent(pct) void
        -ActiveMaterialDynamic : UMaterialInstanceDynamic
    }
    class UBrawlGadgetWidget {
        +SetRemainingCooldown(time) void
        -TextCooldown : UTextBlock
    }

    UBrawlUserWidget <|-- UBrawlSkillWidget
    UBrawlSkillWidget <|-- UBrawlSuperWidget
    UBrawlSkillWidget <|-- UBrawlHyperWidget
    UBrawlSkillWidget <|-- UBrawlGadgetWidget
```

## 5.3 로비 · 메뉴 · 결과 화면

로비 플로우는 `ABrawlLobbyPlayerController`가 메인 위젯을 스왑(`ShowLobby` / `ShowBrawlerSelect` / `ShowGameModeSelect`)하며 구동합니다. 선택 화면은 버튼 위젯(`*Button`)을 동적으로 채웁니다.

```mermaid
classDiagram
    class UBrawlUserWidget
    class UBrawlLobbyWidget
    class UBrawlLobbyBackgroundWidget
    class UBrawlBrawlerSelectWidget
    class UBrawlBrawlerButton
    class UBrawlGameModeSelectWidget
    class UBrawlGameModeButton
    class UBrawlModeSelectWidget
    class UBrawlMatchStartWidget
    class UBrawlMatchResultWidget
    class UBrawlRoundResultWidget
    class UBrawlFinalSummaryWidget
    class UBrawlLoadingWidget {
        <<: UUserWidget>>
    }
    class SBrawlLoadingScreen {
        <<Slate / SCompoundWidget>>
    }
    class APlayerController
    class ABrawlLobbyPlayerController {
        +ShowLobby() void
        +ShowBrawlerSelect() void
        +ShowGameModeSelect() void
        -CurrentMainWidget : UUserWidget
        -BackgroundWidget : UUserWidget
        -LobbyBGM : USoundBase
    }

    UBrawlUserWidget <|-- UBrawlLobbyWidget
    UBrawlUserWidget <|-- UBrawlLobbyBackgroundWidget
    UBrawlUserWidget <|-- UBrawlBrawlerSelectWidget
    UBrawlUserWidget <|-- UBrawlBrawlerButton
    UBrawlUserWidget <|-- UBrawlGameModeSelectWidget
    UBrawlUserWidget <|-- UBrawlGameModeButton
    UBrawlUserWidget <|-- UBrawlModeSelectWidget
    UBrawlUserWidget <|-- UBrawlMatchStartWidget
    UBrawlUserWidget <|-- UBrawlMatchResultWidget
    UBrawlUserWidget <|-- UBrawlRoundResultWidget
    UBrawlUserWidget <|-- UBrawlFinalSummaryWidget
    APlayerController <|-- ABrawlLobbyPlayerController

    ABrawlLobbyPlayerController ..> UBrawlLobbyWidget : 표시
    ABrawlLobbyPlayerController ..> UBrawlBrawlerSelectWidget : 표시
    ABrawlLobbyPlayerController ..> UBrawlGameModeSelectWidget : 표시
    UBrawlBrawlerSelectWidget *-- "*" UBrawlBrawlerButton
    UBrawlGameModeSelectWidget *-- "*" UBrawlGameModeButton
```

> `UBrawlLoadingWidget`(UMG)과 `SBrawlLoadingScreen`(Slate)은 레벨 전환 로딩 화면용으로, `UBrawlGameInstance`가 표시/숨김을 제어합니다.
